Starbase

Starbase is an extensible web application. It supports multiple languages such as English, French, Chinese, and more.

The backend code written in Java, using Rockstar framework. The reference web server is Bobcat, which has been included in this project.

The dictionary is in the table "translations", as follow: 

.---------.------------.----------------.----------------------.
| number  | code       | language       | text                 |
'---------'------------'----------------'----------------------'

  2         home         th-th            หน้าแรก
  3         language     en-us            Language
  4         language     th-th            ภาษา
